# 📧 Spam Detection using LSTM (PyTorch)

A Natural Language Processing (NLP) project built using PyTorch and Long Short-Term Memory (LSTM) networks to classify messages as Spam or Not Spam.

This project demonstrates a complete NLP pipeline from raw text to spam classification.

---

# 🚀 Features

✅ Text Tokenization

✅ Vocabulary Creation

✅ Word-to-Index Mapping

✅ Sequence Padding

✅ Word Embeddings

✅ LSTM Network

✅ Binary Classification

✅ Real-Time Spam Detection

---

---

# 📂 Dataset

The dataset contains spam and non-spam messages.

Examples:

Spam:

- win money now
- claim your free prize
- free iphone click now
- earn money quickly

Not Spam:

- meeting starts at five
- please call me later
- see you tomorrow
- happy birthday friend
